Project Description

A comprehensive web development training program designed for employees of the Daet Local Government Unit. The training covers HTML, CSS, JavaScript, and basic web application development to enhance the digital skills of government workers.

Objectives
  • Train 30 LGU employees on fundamental web development technologies
  • Develop participants' ability to create and maintain basic government websites
  • Provide hands-on project experience in building web applications
  • Deliver training materials and documentation for future reference
